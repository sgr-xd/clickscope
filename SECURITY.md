# Security policy

## Reporting a vulnerability

Report it privately, through GitHub: on this repository open **Security → Report a
vulnerability** ([direct link](https://github.com/sgr-xd/clickscope/security/advisories/new)). Please do not open a public issue, pull request
or discussion about it.

Say what you found, how to reproduce it, and what it affects. This project has one maintainer,
who aims to answer within a week and will credit you in the fix unless you ask otherwise.

## In scope

Anything that could anything that lets a query write or change server state, bypass the read-only policy or its limits, or leak a password or other credential.

## Supported versions

Only the latest release gets security fixes.
